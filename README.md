# sql_data_analysis_EDA
This is a exploratory data analysis project in which data has summarized and visualized.
1. Exploratory Data Analysis (EDA)
   a) The Basics: Finding what's inside our databases, categories, timelines, and big-picture metrics.
   b) The Shapes: Looking at scale, distributions, and sorting out the top and bottom performers.
2. Advanced Analytics:
   a) Trends & Growth: Tracking changes over time, trajectories, and running totals.
   b) Deep Dives: Benchmarking performance, analyzing part-to-whole proportions, and grouping data into distinct behavioral segments.
   Delivery: Bringing it all together into clean, presentation-ready reports.
